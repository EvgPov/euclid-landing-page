# Euclid – Landing Page

Адаптивный лендинг проектного бюро с современным дизайном и интерактивными элементами.

### Реализованные возможности
- Бургер-меню с плавной анимацией для мобильных устройств
- Hero-секция со слайдером на Swiper.js
- Полностью адаптивная вёрстка (от 1920px до мобильных)
- Чистая и структурированная SCSS-архитектура с переменными и миксинами

### Технологии
- **HTML5**
- **SCSS** (переменные, миксины, clamp)
- **JavaScript**
- **Swiper.js**
